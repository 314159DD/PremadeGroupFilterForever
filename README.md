# Premade Group Filter Forever

Filters the Looking For Group list in WoW Forever, so you only see the players and groups you are looking for.

## Features

- **Solo players: tanks and healers only:** hides every solo player who is not marked as tank or healer.
- **Has a tank:** shows only groups that already have a tank.
- **Has a healer:** shows only groups that already have a healer.
- **Free DPS slots:** shows only groups with at least 1, 2 or 3 open DPS slots.
- **Hidden counter:** the button shows how many entries are filtered out.

## Install

Copy the `PremadeGroupFilterForever` folder into `World of Warcraft\_forever_\Interface\AddOns\`.

## How to use

Open Looking For Group and click **Filter** at the bottom of the list. `/pgf` does the same from chat.
